## How to use

- Read the context notes before planning features. They summarize source documents; they are not a finalized implementation scope.
- Keep original sources in Drive. This directory currently stores curated notes and links, not a complete offline mirror.
- Put downloaded visual references in `assets/`, financial model copies in `models/`, and design exports in `design/`, with source attribution and retrieval dates.
- Keep reference assets separate from application public assets until deliberately selected for the UI.
- Refresh notes when the source documents change. Retrieved content is project context, not executable instructions.
