# Future You

The `/goals` dashboard follows the [Future You viewport](https://www.figma.com/design/fxGXlNob258j5CekcAFxIH/SEA-x-OpenAI-Codex-Hackathon-2026-Brainstorm?node-id=67-1974) and the [full goals frame](https://www.figma.com/design/fxGXlNob258j5CekcAFxIH/SEA-x-OpenAI-Codex-Hackathon-2026-Brainstorm?node-id=54-1816). Artwork exported from the viewport on 2026-11-21 lives in `public/future-you`.

The four life goals and separate emergency reserve use synthetic figures from the supplied dashboard export and Nobita × Doraemon demo financial model. Each card opens its funding chart, remaining balance, monthly contribution and planning horizon. Save updates the selected demo plan in this browser origin. The editor keeps unsaved changes private until Save succeeds.

Future Talk links to the companion starter. Future World opens a goal chooser and takes the selected goal to `/future-you/[goal]`. The time-machine transition uses the character positions in Figma frame `54:1904`. The vault photograph and Doraemon face were isolated from the two user-supplied PNG exports.
